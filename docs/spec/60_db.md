# 60_db

## スコープ
- PostgreSQL
- Redis
- Storage

## 方針
- いずれも private endpoint + private DNS を前提とする。
- Public Network Access は無効化を基本とする。

## 接続要件（例）
- PostgreSQL: 5432
- Redis: 6380(TLS)
- Storage: private endpoint 経由

## 未確認事項（spec未記載・コード記載）
- `infra/modules/postgresql.bicep` は PostgreSQL Flexible Server `version: '14'`、`Standard_B1ms`、バックアップ7日、HA無効。
- `infra/modules/postgresql.bicep` は `dify`/`vector` DB作成と `azure.extensions=uuid-ossp,vector` を設定。
- `infra/modules/redis-cache.bicep` は Redis `basic/C0`、`publicNetworkAccess: 'Disabled'`、TLS1.2、Private Endpoint構成。
- `infra/modules/storage.bicep` は blob/file のPrivate EndpointとPrivate DNSを作成し、`networkAcls.defaultAction: 'Deny'` を設定。
