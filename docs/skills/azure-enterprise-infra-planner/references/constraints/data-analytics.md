# Data (Analytics)

## Common resources

- Cosmos DB (`Microsoft.DocumentDB/databaseAccounts`)
- Azure Cache for Redis (`Microsoft.Cache/redis`)
- Storage Account (`Microsoft.Storage/storageAccounts`)
- Data Factory (`Microsoft.DataFactory/factories`)
- Synapse (`Microsoft.Synapse/workspaces`)

## Planning notes

- Confirm consistency, replication, backup, retention, and private endpoint requirements.
- Storage account names are globally unique and must meet naming rules.
- Consider encryption, diagnostic settings, lifecycle policies, and data exfiltration controls.
