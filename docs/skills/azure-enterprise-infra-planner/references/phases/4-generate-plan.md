# Phase 4: Generate Plan

Create the infrastructure plan artifacts.

- Write `/.azure/infra-plan.json` using [schema.md](../schema.md).
- Write `/.azure/infra-plan.md` as a readable summary.
- Set `meta.status` to `draft` unless the user explicitly approves the plan.
- Include architecture decisions, alternatives considered, risks, cost notes, and unresolved questions.
