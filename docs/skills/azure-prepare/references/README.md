# Azure Prepare References

This directory stores the reference bundle associated with the `azure-prepare` skill.

The upstream bundle is published by Microsoft in the `microsoft/azure-skills` repository under `skills/azure-prepare/references/`. It contains progressive-disclosure guidance for:

- planning: analyze, requirements, scan, recipe selection, architecture, and plan template;
- recipes: AZD, Azure CLI, Bicep, and Terraform;
- runtimes and SDKs: Node.js, Azure Developer CLI, Azure Identity, and App Configuration;
- services: AKS, App Service, Container Apps, Cosmos DB, Durable Task Scheduler, Event Grid, Azure Functions, Foundry, Key Vault, Logic Apps, Service Bus, SQL Database, Static Web Apps, and Storage;
- security, Azure context confirmation, resource limits, functional verification, and specialized routing.

Use this directory as the local destination for the upstream `references/` content when updating the repository copy.
